HP Prime Reference Guide

Select an item from the Catalog pop-up menu to view its documentation. The catalog provides a comprehensive reference for HP Prime functions, commands, constants and PPL language keywords, including their descriptions, syntax, parameters and usage examples where available.

Use the catalog to explore the available functionality, understand how individual commands work and find the information you need when writing or editing PPL programs. Select any item to display its corresponding documentation, making it easy to look up language features and refer to their usage without leaving Xprime.
